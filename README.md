## 🚀 À propos

Développeur Full Stack passionné par la création d'applications web modernes et performantes. Je combine expertise frontend et backend pour livrer des solutions complètes, du design à la mise en production.

**Mes forces :**
- Développement d'interfaces utilisateur réactives avec React et Next.js
- Architecture backend robuste avec Node.js, Laravel et Spring Boot
- Maîtrise de TypeScript pour un code type-safe et maintenable
- Expérience avec les CI/CD et le déploiement conteneurisé
